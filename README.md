## Теоретическая часть

### 1. Связь между UI/UX и версткой
UI (User Interface) — визуальная часть интерфейса, UX (User Experience) — взаимодействие пользователя с системой.  
Главная задача разработчика интерфейса — перенести визуальные решения из дизайна в код, сохранив композицию, цветовую палитру и удобство использования.

### 2. Экспорт параметров из Figma
В Figma можно получить значения:
- цвета (HEX);
- отступы (Padding/Margin);
- размеры и радиусы;
- шрифты (название, вес, размер).

Для ускорения верстки используются плагины: **Figma → Flutter**, **Figma Tokens**, **Design to Code**.

### 3. Структура проекта Flutter для UI-разметки
/lib
/screens // экраны приложения
/widgets // переиспользуемые компоненты
/theme // стили, цвета, шрифты
main.dart


Такой подход обеспечивает масштабируемость и чистую архитектуру кода.

### 4. Основные виджеты Flutter
Container, Padding, Align, Center — для компоновки;  
Column, Row, Stack — для размещения элементов;  
Image.asset — для изображений;  
Text, TextStyle — для стилизации текста;  
ListView, SingleChildScrollView — для прокрутки;  
Navigator.push() — для перехода между экранами.

### 5. Адаптивность интерфейса
Flutter автоматически масштабирует интерфейс, но рекомендуется использовать относительные размеры (MediaQuery, Expanded, Flexible) вместо фиксированных значений.

### 6. Цветовая палитра и шрифты
В Flutter палитру и текстовые стили удобно выносить в отдельные файлы, например:

```dart
class AppColors {
  static const primary = Color(0xFF1E88E5);
  static const accent = Color(0xFFFFC107);
  static const background = Color(0xFFF5F5F5);
}

class AppTextStyles {
  static const title = TextStyle(
    fontSize: 24,
    fontWeight: FontWeight.bold,
  );
}
```
7. Навигация между экранами
Навигация реализуется с помощью Navigator.push() и Navigator.pop() или библиотеки go_router для более сложных сценариев.

Практическая часть
Задание
Сверстать мобильное приложение по макету MAD Shopp Mobile App Design.

Алгоритм выполнения
Создание проекта:


flutter create madshop_ui_demidov
Проект открыт в VS Code / Android Studio.

Подготовка структуры:

```
lib/
  main.dart
  screens/
    home_screen.dart
    product_screen.dart
    cart_screen.dart
  widgets/
    product_card.dart
  theme/
    colors.dart
    text_styles.dart
```
Импорт ресурсов:

Добавлены изображения и иконки в assets/images/;

Зарегистрированы в pubspec.yaml.

Верстка экранов:

Главный экран: список карточек товаров (GridView / ListView.builder);

Экран товара: изображение, описание, цена, кнопка «Добавить в корзину»;

Корзина: список выбранных товаров, итоговая сумма.

Навигация:

```
Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => ProductScreen()),
);
```
Работа со стилями:

Цвета и шрифты вынесены в отдельные файлы;

Использован ThemeData для единого оформления приложения.

Проверка соответствия дизайну:

Отступы и размеры соответствуют макету;

Цвета и шрифты идентичны Figma;

Приложение протестировано на различных размерах экранов.
